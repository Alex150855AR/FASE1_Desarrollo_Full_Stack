# Sistema de Gestión de Proyectos - Fase 1

Como Ingeniero de Software Full Stack, este es el repositorio principal para la plataforma de gestión de proyectos.

## 🏗️ Arquitectura del Proyecto

Usuario -> Frontend (React)
Frontend (React) -> Componentes UI
Frontend (React) -> Manejo de Estados
Frontend (React) -> Peticiones HTTP REST -> Backend (Node.js y Express)
Backend (Node.js y Express) -> Rutas de la API
Rutas de la API -> Controladores
Controladores -> Consultas -> Base de Datos (Simulada)

## 🛠️ Stack Tecnológico
* **Frontend:** React, HTML, CSS, JavaScript
* **Backend:** Node.js, Express
